## 2024-07-29 - Use Ant Design Empty Component
**Learning:** When displaying empty states for missing or unloaded data (like empty models or missing server configs), plain text like `<Typography.Text type="secondary">` looks visually inconsistent and lacks polish.
**Action:** Replace plain text placeholders with Ant Design's `<Empty image={Empty.PRESENTED_IMAGE_SIMPLE} description="..." />` component to maintain visual consistency and improve the interface's empty state design.
