- 当前分支为 `codex/pr495-review-fixes`；不切换master、不覆盖18项已有暂存内容。不进行实机、相机或推流操作。

- 本地原始清单和执行记录置于本轮专属忽略目录；脱敏结论入docs。二进制、完整日志和本机绝对路径清单不入库。

## 审查重点

| 场景 | 判据 |
|---|---|
| 表格损坏、ncnn配置混淆 | 以CMakeCache与摘要为准，保留当前ncnn开启分支 |
| 移动破坏相对引用或历史来源 | 以同一转换族成组归档，保留来源和路径映射；父图及消费件留址 |
| 工具仍依赖历史盘符、环境转储或手工JAR | 显式参数、固定来源、无原始敏感输出、Java可重建 |
| 错ABI、缺库、TEXTREL、系统桩、错误类版本 | 静态校验拒绝；不将静态结果宣称运行时验收 |
| 越界、链接、集合/摘要漂移或占用 | 删除前整批拒绝；部分失败准确记录，停止剩余操作 |
